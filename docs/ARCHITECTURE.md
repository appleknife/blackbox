# Architecture

## Shape

SwiftUI app, iOS 17 minimum, one tab shell over a grid of modules. The project
is generated by XcodeGen from `project.yml`. No third-party packages.

`BlackboxTunnel` is a `NEPacketTunnelProvider` extension. `Shared/` holds the
pcap writer and IP parser so both targets agree on the capture format.

## Threading

- UI and `CaseLog` are `@MainActor`.
- `HostSweeper` fans out `NWConnection` probes in task groups of 24 hosts; each
  probe is a 50 ms poll loop capped at ~0.6 s, with one 512-byte receive for
  banners. A lock box bridges the connection callbacks.
- `BLEExplorer` and `NFCBench` are main-actor objects; CoreBluetooth and CoreNFC
  callbacks arrive `nonisolated` and hop with `Task { @MainActor }`.
- The tunnel runs its relay on a serial queue and injects packets from the
  provider. The pcap writer has its own queue.

## Packet path

1. `startTunnel` sets a default IPv4 route, MTU 1400, and Cloudflare/Quad9 DNS.
2. `readPackets` hands raw IPv4 to `TunnelRelay`.
3. Every packet is appended to a pcap with `LINKTYPE_RAW`.
4. TCP: SYN opens an outbound connection, sequence and ack numbers are tracked,
   payload is spliced with window-friendly 1200-byte chunks. FIN or timeout
   tears the flow down.
5. UDP: one outbound socket per five-tuple, replies injected back.
6. Non-IP traffic is captured and dropped.

The relay is the least proven part of the codebase. It is a v0 splice, not a
stateful TCP stack: retransmits, SACK and odd window scaling are not modelled.

Captures land in the App Group at `captures/capture-<epoch>.pcap`.

## Case file

`CaseLog` keeps an in-memory ring of 800 entries and appends JSONL to
`Documents/case-<caseNumber>.jsonl`. Entries carry an id, ISO-8601 date, module
code, kind (`observation`, `finding`, `note`, `error`) and free-form fields.
Export writes pretty JSON to a temp file and opens the share sheet. "Wipe"
starts a fresh case number.

## Entitlements

| Key | Used by |
| --- | --- |
| `com.apple.developer.networking.networkextension` (`packet-tunnel-provider`) | tap |
| `com.apple.developer.networking.wifi-info` | SSID/BSSID |
| `com.apple.developer.nfc.readersession.formats` | tag reading |
| `com.apple.developer.nfc.hce` + `select-identifier-prefixes` | emulation |
| `com.apple.security.application-groups` | capture files |

Free provisioning cannot issue Network Extension or App Group entitlements. HCE
is Apple-managed and needs a request; remove those keys if signing refuses.

## Deliberate choices

- **No third-party dependencies.** Everything is Foundation, Network,
  CoreBluetooth, CoreNFC, CryptoKit and SwiftUI.
- **Generated project.** `project.yml` is reviewable; `.xcodeproj` is not.
- **Fail loud in the UI.** Missing entitlements, denied radios and no Wi-Fi each
  produce a named message instead of an empty screen.
- **Local only.** No account, no telemetry, no upload. The only network calls are
  the ones a module makes on purpose.

## Known gaps

- No retransmission handling; a lossy link will stall flows.
- No IPv6 relay, though IPv6 packets are captured.
- Sweep is fixed to a /24 and a fixed port list.
- No dark/light switch, no iPad-specific layout, no icon set yet.
- NFC emulation answers `90 00` to every APDU; it does not parse SELECT.
